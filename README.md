🔮 Análise Preditiva

Este repositório reúne as aulas, atividades práticas, questionários e materiais de apoio da disciplina de Análise Preditiva do curso de Tecnologia em Ciência de Dados para Negócios da FATEC Votorantim (1º semestre de 2026).

O conteúdo abrange desde os fundamentos de modelagem preditiva até técnicas avançadas de Aprendizado de Máquina, incluindo Regressão Logística, Regressão Linear, k-Nearest Neighbors (KNN), Árvores de Decisão, Random Forest (RF), Gradient Boosted Trees (GBT) e Redes Neurais Aplicadas.
